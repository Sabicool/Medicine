# Classification
- Stage 1: mild hypothermia (conscious, shivering, core temperature 32-35°C)
- Stage 2: moderate hypothermia (impaired consciousness without shivering, core temperature 28-32°C)
- Stage 3: severe hypothermia (unconscious, vital signs present, core temperature 24-28°C)
- Stage 4: cardiac arrest or low flow state (no or minimal vital signs, core temperature <24°C)
- Stage 5: death, due to irreversible hypothermia (core temperature < 13.7°C)
