# In ICU
## Aetiologies

| Infective (50%)         | Non-Infective (50%)                                                                                                     |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| Pneumonia               | Procedure-related (e.g. haemodilaysis, 1-3 days post surgery)                                                           |
| C. difficile            | Drug fever                                                                                                              |
| Surgical site infection | Febrile transfusion reaction                                                                                            |
| Line infection          | Sterile inflammation (e.g. [[Pancreatitis]], [[Aspiration pneumonitis]], [[Acute Respiratory Distress Syndrome\|ARDS]]) |
|                         | [[Pulmonary Embolism]]                                                                                                  |
|                         | [[Alcohol Withdrawal]]                                                                                                  |
|                         | Central fever (e.g. intracranial haemorrhage)                                                                           |
